# ⏱️ Chytré hodiny

Krátký html projekt, pomoc s produktivitou.

## Co to umí?

- Ukázat dnešní datum a čas
- Jednoduché stopky
- Nastavitelný časovač
- Animované a vlastní pozadí (v repozitáři nebo vlasstní složce)

## Cíl projektu
Vytvořit jednoduchou obrazovku s časem, pro produktivní trávení času.
